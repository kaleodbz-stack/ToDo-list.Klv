# 📝 To Do List

Um aplicativo simples de lista de tarefas desenvolvido com o framework **Kivy**, ideal para gerenciar suas atividades diárias.  
O projeto permite **criar novas tarefas** e **marcar quando forem concluídas**, salvando todas as informações em um arquivo **JSON** local.

---

## ⚙️ O que o projeto faz

O **To Do List** tem duas funções principais:

- ✅ **Adicionar Tarefa:** o usuário pode criar novas tarefas a qualquer momento.  
- ✔️ **Marcar como Concluída:** ao terminar uma tarefa, é possível marcá-la como feita, mantendo o controle do progresso.  

As tarefas são salvas automaticamente em um arquivo **JSON**, garantindo que seus dados sejam mantidos mesmo após fechar o aplicativo.

---

## 💡 Como funciona

O projeto utiliza o **Kivy**, um framework Python voltado para o desenvolvimento de interfaces gráficas multiplataforma.  
As principais características do funcionamento são:

1. Ao abrir o app, o programa carrega as tarefas salvas no arquivo `data.json`.  
2. O usuário pode adicionar novas tarefas através da interface gráfica.  
3. Cada tarefa pode ser marcada como feita ou não feita.  
4. As mudanças são salvas automaticamente no arquivo `data.json`.  

Assim, o aplicativo mantém um histórico atualizado das tarefas criadas e concluídas.

---

## 🧩 Tecnologias utilizadas

- 🐍 **Python 3**
- 🎨 **Kivy Framework**
- 💾 **JSON** (para armazenamento local dos dados)
